# 📱 Using Cortex on Android - Quick Guide

## First Launch

When you first open Cortex on Android, you'll see:
- A **Welcome.md** file with instructions
- Your files in the sidebar
- Two buttons at the top

## The Buttons

### 📁 Storage Info
Shows you where your files are stored:
- Location: `Documents/cortex-vault/`
- You can access these files with any file manager app
- Files are standard markdown (.md) files

### ➕ New File
Creates a new markdown file:
1. Tap the button
2. Enter a file name (without .md extension)
3. The file opens automatically
4. Start typing!

## Navigation

### Finding Files

**Option 1: Sidebar**
- Scroll through the file list
- Tap any file to open it

**Option 2: Quick Search (Recommended!)**
- Tap the search icon (if visible)
- Or use CTRL+P keyboard shortcut
- Type to search across all files
- Results appear instantly with fuzzy matching

## Editing Features

### Auto-Save
- Your changes save automatically as you type
- No save button needed!
- Files update in real-time

### Markdown Support
- **Bold** with `**text**`
- *Italic* with `*text*`
- `Code` with backticks
- Links, lists, headings, and more!

### Rich Editing
- Task lists with checkboxes
- Tables (tap to edit cells)
- Code blocks with syntax highlighting
- Inline highlighting

## File Management

### Creating Files
Use the **+ New File** button at the top

### Accessing Files Outside Cortex
1. Open any file manager app on Android
2. Navigate to `Documents/cortex-vault/`
3. Your markdown files are there!
4. You can:
   - Copy files to/from other apps
   - Share files
   - Backup to cloud storage
   - Edit with other markdown apps

### Organizing Files
Currently files are stored flat in the vault folder. Future updates will add:
- Folder creation
- File moving/renaming
- Better organization

## Tips & Tricks

### Quick Search
The search is **fuzzy** - you don't need exact matches:
- Type "mtg" to find "meeting-notes.md"
- Type "idea" to find all files with "idea" in the name
- Use arrow keys to navigate results
- Press Enter to open

### Keyboard Shortcuts
- **CTRL+P** - Quick search
- **ESC** - Close search dialog

### Performance
- Cortex works offline (no internet needed)
- Files load instantly
- Smooth scrolling on most devices

### Touch Gestures
- Tap files to open
- Scroll through file list
- All buttons are touch-optimized

## Troubleshooting

### Can't See My Files
1. Tap **Storage Info** to see the location
2. Files are in `Documents/cortex-vault/`
3. Use a file manager app to verify

### File Not Saving
- Files auto-save as you type
- No manual save needed
- Check storage permissions in Android settings

### App Crashes
- Check Android version (requires Android 7+)
- Clear app cache in settings
- Reinstall if needed

### Welcome File Reappears
- The Welcome.md file is created if vault is empty
- Just delete it and create your own files
- It won't come back once you have other files

## What's Different from Desktop?

| Feature | Desktop | Android |
|---------|---------|---------|
| File Location | You choose | Auto: Documents/cortex-vault |
| Folder Picker | Native dialog | Fixed location |
| File Creation | Via file system | + New File button |
| Sidebar | Resizable | Fixed width, collapsible |
| Storage | Anywhere | App's Documents folder |
